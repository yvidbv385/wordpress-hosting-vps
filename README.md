## 托管型和自管 VPS，先分清这两条路线

核心区别就一条：运维交给谁。托管型 WordPress 主机（共享主机）的本质是“合租”——你拿到控制面板和一套预设环境，PHP 版本、防火墙、每日备份都由主机商处理，出问题发工单。评估时看四个指标就够：在线率、速度、价格配置、客服。在线率方面，99.9% 意味着一年最多宕机约 8.7 小时，主流商家的实际数据都在 99.9% 以上，差距不大；真正拉开距离的是速度和配置。

自管 VPS 则是一台完整的虚拟服务器：root 权限、独立 IP、想装什么装什么。WordPress 本身对环境要求不高，1GB 内存的机器跑一个轻量博客绰绰有余。代价是所有运维归你——装环境、配证书、做备份、堵漏洞，主机商只保证机器在线，网站挂了得自己查。

一句话判断：只有一两台正式站、时间想花在内容上，选托管型；预算敏感、站点多、想把环境完全握在手里，选 VPS。两条路线也不冲突，很多人是托管跑主力站、VPS 挂测试站。如果既想要独立资源又不想管运维，中间还有 Cloudways 这类托管云主机，价格介于两者之间。

4. **装 WordPress 和缓存**：上传安装 WordPress，配 LiteSpeed Cache 或同类缓存插件。
5. **自己搭备份**：面板计划任务每日打包数据库和文件，再同步一份到对象存储或另一台机器。这步别省——托管型的“每日自动备份”，在 VPS 上就是你自己的活。

安全方面做好三件基础事：SSH 改用密钥登录、开启面板自带防火墙、插件主题保持更新。做到这些，轻量站的稳定性不会比共享主机差。

## 常见问题

**RackNerd 这么便宜，跑 WordPress 会慢吗？**
取决于配置和优化习惯。1GB 内存跑轻量博客加缓存插件够用；主题插件堆得多（比如重型主题再加多语言），直接上 2.5GB 的 Tiny 更稳。共享主机的 CPU 和内存同样有限制，只是写在条款里，不像 VPS 摆在明面上。

**续费会不会涨价？**
常规套餐按标价循环，促销套餐大多标注循环价，具体以下单页为准。对比 SiteGround 最低档续费 $14.99/月、Hostinger Basic 续费 $5.99/月，RackNerd 至少没有“首年钩子价”这套玩法。

**完全不懂命令行，能买吗？**
不建议第一台主机就选自管 VPS。先用托管型把站跑起来，熟悉面板和基本运维后再迁。迁移本身不难，All-in-One WP Migration 这类插件可以自助完成整站搬家。

**退款政策怎么样？**
VPS 类产品和共享主机的退款规则不同，各家条款差异也大，下单前把官网服务条款里的退款部分读完再付款，尤其是年付订单。
